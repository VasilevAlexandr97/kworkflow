# KworkFlow

KworkFlow — сервис для мониторинга фриланс-биржи Kwork. Отслеживает новые проекты и доставляет подходящие заказы пользователям в Telegram в режиме реального времени, а также автоматически генерирует отклики на проекты с помощью ИИ на основе профиля фрилансера и текста заказа. Расширенные возможности доступны по подписке PRO.

🤖 Бот: [@kworkflowbot](https://t.me/kworkflowbot) · 🌐 Сайт: [kworkflow.ru](https://kworkflow.ru)

## Возможности

- 📡 Мониторинг новых проектов на Kwork и мгновенная доставка подходящих заказов в Telegram
- 🗂 Подписка на интересующие категории проектов
- 🧹 Фильтрация заказов по стоп-словам и диапазону цены
- 🤖 Генерация откликов на проекты с помощью ИИ на основе профиля пользователя и текста заказа
- 👤 Профиль фрилансера, используемый ИИ при составлении откликов
- 💎 Отправка высокобюджетных проектов (от 30 000 ₽) в публичный Telegram-канал
- 👑 Подписка PRO: пробный период 3 дня за 1 ₽, далее 349 ₽ в месяц
- 💳 Оплата картой через YooKassa и автопродление подписки
- 🔔 Уведомления о статусе подписки: активация, продление, проблемы с оплатой, отключение
- 🆓 Ограничения бесплатного тарифа: 1 категория, 5 стоп-слов, 3 генерации откликов
- 🌐 Маркетинговый сайт с описанием сервиса, тарифами и FAQ
- 🛠 Админ-панель для управления пользователями, проектами и сгенерированными откликами
